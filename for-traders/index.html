Install extensions to pull live data directly into cells. No API keys needed for most.

Stock Quotes

stocks: AAPL

Live price, daily change (▲▼), 52-week range, volume via Yahoo Finance. Batch mode: stocks: AAPL, MSFT, GOOGL for comparison tables. Auto-refreshes every 60s.

₿

Crypto Prices

price: bitcoin

Real-time crypto prices from CoinGecko. Supports 10,000+ coins. Shows USD price, 24h change, market cap. No API key required.

💱

FX Rates

fx: USD/EUR

Live foreign exchange rates. Track currency pairs relevant to your positions. Auto-refresh keeps you current without switching windows.

📉

Sparkline Charts

s: 142,145,143,148,152

Unicode block-bar charts in a single cell. Visualize price trends, volume patterns, or P/L history. Compact and always visible.

🌐

Live Web Fetch

w: https://api.example.com/quote

Pull any JSON endpoint into a cell. Build custom feeds from your broker's API, economic calendars, or earnings data.

⏰

Market Hours Clock

ext: worldtm NY,London,Tokyo

Multiple time zones with business-hours indicators (🟢 open / 🔴 closed). Know when NYSE, LSE, and TSE are trading at a glance.

✅ Why Traders Choose QuickSheet

  • 🔒 Zero Subscription Fees

    No Bloomberg terminal costs. No monthly SaaS. Free and open-source forever. Uses free public APIs (Yahoo Finance, CoinGecko).

  • 👁️ Always Visible

    Your positions live on your wallpaper. No need to switch windows, open browser tabs, or check your phone. Glance at your desktop — done.

  • ⚡ Lightweight & Fast

    Uses ~30MB RAM. No Electron bloat. No web browser overhead. Starts instantly. Runs silently in the background while you focus on execution.

  • 🔌 Extensible

    Build your own data feeds. The extension protocol is JSON-lines over stdin/stdout — plug in any API, any language. Custom alerts, custom formulas, custom views.

  • 📊 Sparklines in Cells

    Compact unicode charts show price trends at a glance. No need for full charting software to spot momentum or reversals. One cell, one trend.

  • 🖥️ Cross-Platform

    Works on Windows (WinForms) and Linux (X11). Same CSV, same extensions, same workflow. Your watchlist travels with you.

🚀 Get Started in 3 Minutes

  1. Clone & Build git clone https://github.com/cemheren/QuickSheet && cd QuickSheet && dotnet build
  2. Install Extensions Launch QuickSheet, then type in any cell: ext: github:cemheren/quicksheet-stocks — it installs automatically. Repeat for quicksheet-fx and quicksheet-price.
  3. Build Your Watchlist Type stocks: AAPL in cell A1, price: bitcoin in A2, fx: USD/EUR in A3. Data flows in automatically.
  4. Launch as Desktop dotnet run -c Release --project ExcelConsole.csproj -- --desktop
    Your watchlist is now your wallpaper. Always on. Always current.
